# Instructional Designer Portfolio

A minimal, single-page portfolio with a cream background, a subtle connection-line and lightbulb pattern, and a header that fades to transparent as you scroll.

## Files

- `index.html` – page content (edit your name, bio, stats, projects, skills, contact)
- `styles.css` – colours, layout and the background pattern
- `script.js` – header fade, scroll reveal, footer year

## Customize

1. Replace "Your Name", the bio, and the three stats in `index.html`.
2. Update the three project cards and link each to a case study or sample.
3. Add your resume as `resume.pdf` in the repo root (or change the link).
4. Update the email, LinkedIn and phone links in the footer.
5. Colours live at the top of `styles.css` under `:root`.

## Publish with GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
